# CPE-316-P1-Lockbox
Utilizing external keypad input and LCD output, this project aimed to create a digital lock with a set 4 digit keycode that the user can input via the keypad to ‘unlock’ the device, and if the input does not match the device will clear the input and prompt the user to try another 4 digit input. Once the correct input had been entered, the device will switch to the unlocked state, prompting the user to input the pound # key on the keypad to re-lock the device or the * key to reset the keycode. Also, while the user is inputting a digit, each digit will be displayed for the user to see on the LCD, cleared when the device has unlocked or reentered the locked state after invalid keycode input.
